# Discord Бот для Организации Пользовательских Матчей (Scrims)

## 1. Обзор

Этот Discord бот предназначен для упрощения организации пользовательских матчей (скримов) на вашем сервере. Он позволяет пользователям регистрироваться на матчи, автоматически распределяет их по командам, проводит голосование за составы и включает систему репутации для оценки игроков. Бот разработан с использованием `py-cord` (Discord.py) и включает модульную структуру с использованием когов для удобства расширения.

## 2. Возможности

*   **Регистрация на матчи**: Пользователи могут регистрироваться и отменять регистрацию на предстоящие матчи.
*   **Автоматическое формирование команд**: После набора достаточного количества игроков бот автоматически распределяет их по двум командам.
*   **Гибкая настройка количества игроков**: Администраторы могут устанавливать желаемое количество игроков в команде.
*   **Голосование за составы**: После формирования команд игроки могут проголосовать за утверждение составов или за их перемешивание.
*   **Система репутации**:
    *   Игроки могут оценивать друг друга (положительно или отрицательно) после матчей (хотя команда доступна и вне матчей).
    *   Просмотр собственной репутации.
    *   Просмотр топа игроков по репутации.
*   **Административные команды**: Набор команд для управления регистрацией, игроками и настройками бота.
*   **Автоматический сброс состояния**: Если матч не начинается или регистрация не завершается в течение определенного времени, состояние игры автоматически сбрасывается.
*   **Приветственные сообщения**: Бот отправляет приветственное сообщение при подключении/готовности.
*   **Модульная структура (коги)**: Команды разделены на пользовательские (`UserCog`) и административные (`AdminCog`) для лучшей организации.
*   **Управление когами**: Администраторы бота могут загружать, выгружать и перезагружать коги без перезапуска бота.

## 3. Команды Бота

Все команды являются слэш-командами (вызываются через `/`).

### 3.1. Пользовательские Команды (`UserCog`)

Эти команды доступны всем пользователям сервера.

*   **/start\_registration**
    *   **Описание**: Начинает процесс регистрации игроков на новый матч и отображает кнопки для регистрации/отмены регистрации.
    *   **Параметры**:
        *   `players_per_team` (Целое число, Опционально, по умолчанию 5, мин: 2, макс: значение из `config.MAX_PLAYERS_PER_TEAM`): Количество игроков в каждой команде.
    *   **Права**: Только для пользователей с правом "Управлять событиями" на сервере.
    *   **Примечание**: Если уже идет регистрация или есть зарегистрированные игроки, команду нельзя использовать без предварительной остановки текущей регистрации (`/stop_registration`).

*   **/register**
    *   **Описание**: Регистрирует пользователя на текущий матч. Рекомендуется использовать кнопки, создаваемые командой `/start_registration`.
    *   **Параметры**: Нет.
    *   **Права**: Все пользователи.

*   **/unregister**
    *   **Описание**: Отменяет регистрацию пользователя на текущий матч. Рекомендуется использовать кнопки, создаваемые командой `/start_registration`.
    *   **Параметры**: Нет.
    *   **Права**: Все пользователи.

*   **/show\_teams**
    *   **Описание**: Показывает текущие составы команд без запуска голосования. Сообщение видно всем.
    *   **Параметры**: Нет.
    *   **Права**: Все пользователи.

*   **/info**
    *   **Описание**: Выводит подробную информацию о текущем состоянии регистрации: количество игроков, список зарегистрированных, статус голосования (если активно). Сообщение видно только вызвавшему пользователю.
    *   **Параметры**: Нет.
    *   **Права**: Все пользователи.

*   **/rate\_player**
    *   **Описание**: Позволяет оценить другого игрока (повысить или понизить его репутацию).
    *   **Параметры**:
        *   `user` (Пользователь, Обязательно): Игрок, которого вы хотите оценить.
        *   `rating` (Строка, Обязательно, варианты: "positive", "negative"): Тип оценки.
        *   `reason` (Строка, Опционально, макс. 100 символов): Причина оценки.
    *   **Права**: Все пользователи.
    *   **Примечание**: Нельзя оценивать самого себя.

*   **/my\_reputation**
    *   **Описание**: Показывает ваш текущий уровень репутации. Сообщение видно только вам.
    *   **Параметры**: Нет.
    *   **Права**: Все пользователи.

*   **/top\_reputation**
    *   **Описание**: Показывает топ игроков по уровню репутации.
    *   **Параметры**:
        *   `count` (Целое число, Опционально, по умолчанию 5, мин: 1, макс: 15): Количество игроков для отображения в топе.
    *   **Права**: Все пользователи. Сообщение видно всем.

### 3.2. Административные Команды (`AdminCog`)

Эти команды предназначены для администраторов сервера или бота.

*   **/admin\_register**
    *   **Описание**: [АДМИН] Принудительно зарегистрировать указанного игрока на матч.
    *   **Параметры**:
        *   `member` (Пользователь, Обязательно): Участник сервера для регистрации.
    *   **Права**: Только для пользователей с правом "Управлять событиями". Доступность команды может быть ограничена определенными серверами (`ADMIN_GUILD_IDS` в `config.py`).

*   **/admin\_unregister**
    *   **Описание**: [АДМИН] Принудительно отменить регистрацию указанного игрока с матча.
    *   **Параметры**:
        *   `member` (Пользователь, Обязательно): Участник сервера для отмены регистрации.
    *   **Права**: Только для пользователей с правом "Управлять событиями". Доступность команды может быть ограничена определенными серверами.

*   **/set\_players**
    *   **Описание**: [АДМИН] Изменить количество игроков в каждой команде для текущей или следующей регистрации.
    *   **Параметры**:
        *   `number` (Целое число, Обязательно, мин: 1, макс: значение из `config.MAX_PLAYERS_PER_TEAM`): Новое количество игроков в команде.
    *   **Права**: Только для пользователей с правом "Управлять событиями". Доступность команды может быть ограничена определенными серверами.

*   **/stop\_registration**
    *   **Описание**: [АДМИН] Остановить текущий процесс регистрации и полностью очистить список зарегистрированных игроков, сбросив состояние игры.
    *   **Параметры**: Нет.
    *   **Права**: Только для пользователей с правом "Управлять событиями". Доступность команды может быть ограничена определенными серверами.

*   **/force\_voice\_moving**
    *   **Описание**: [АДМИН] Принудительно запустить процесс распределения зарегистрированных игроков по голосовым каналам команд. Полезно, если автоматическое распределение не сработало.
    *   **Параметры**: Нет.
    *   **Права**: Только для пользователей с правами "Управлять событиями" И "Перемещать участников". Доступность команды может быть ограничена определенными серверами.

*   **/clear\_bot\_messages**
    *   **Описание**: [АДМИН] Удалить все сообщения, отправленные этим ботом, из канала, где была вызвана команда, за последние N дней.
    *   **Параметры**:
        *   `days` (Целое число, Опционально, по умолчанию 14, мин: 1, макс: 30): Количество дней, за которые удалить сообщения.
    *   **Права**: Только для пользователей с правом "Управлять сообщениями" И являющихся администраторами бота (см. `BOT_ADMIN_USER_IDS` в `config.py`). Доступность команды может быть ограничена определенными серверами.

### 3.3. Команды Управления Ботом (в `bot.py`)

Эти команды предназначены только для глобальных администраторов бота, указанных в `config.py`.

*   **/load\_cog**
    *   **Описание**: [АДМИН БОТА] Загрузить указанный ког.
    *   **Параметры**:
        *   `cog_name` (Строка, Обязательно): Имя файла кога без расширения `.py` (например, `user_cog`).
    *   **Права**: Только для администраторов бота (`BOT_ADMIN_USER_IDS`).

*   **/unload\_cog**
    *   **Описание**: [АДМИН БОТА] Выгрузить указанный ког.
    *   **Параметры**:
        *   `cog_name` (Строка, Обязательно): Имя файла кога без расширения `.py`.
    *   **Права**: Только для администраторов бота.

*   **/reload\_cog**
    *   **Описание**: [АДМИН БОТА] Перезагрузить указанный ког.
    *   **Параметры**:
        *   `cog_name` (Строка, Обязательно): Имя файла кога без расширения `.py`.
    *   **Права**: Только для администраторов бота.

## 4. Система Репутации

Система репутации позволяет игрокам влиять на рейтинг друг друга.

*   **Оценка**: Игроки могут использовать команду `/rate_player`, чтобы поставить положительную (+1) или отрицательную (-1) оценку другому игроку.
*   **Просмотр**: Команда `/my_reputation` показывает собственный рейтинг, а `/top_reputation` — список игроков с наивысшей репутацией.
*   **Механизм**: В текущей реализации система просто суммирует полученные очки. Сложные механизмы предотвращения накрутки (например, ограничение частоты оценок одного и того же игрока) пока не реализованы, но могут быть добавлены в будущем.

## 5. Установка и Запуск

1.  **Клонируйте репозиторий** (если применимо).
2.  **Установите зависимости**:
    ```bash
    pip install -U py-cord
    ```
3.  **Настройте `config.py`**:
    *   Скопируйте `config.example.py` в `config.py`.
    *   Заполните необходимые значения: `TOKEN` (токен вашего бота), `GAME_CHANNEL_ID` (ID канала для регистрации и сообщений), `VOICE_CHANNEL_ID_TEAM1`, `VOICE_CHANNEL_ID_TEAM2` (ID голосовых каналов для команд), `GUILD_ID` (ID вашего сервера), а также списки ID администраторов.
4.  **Запустите бота**:
    ```bash
    python bot.py
    ```
5.  **Пригласите бота на ваш сервер**: Используйте стандартный процесс приглашения ботов Discord, убедившись, что у бота есть необходимые права (чтение сообщений, отправка сообщений, управление событиями, перемещение участников, управление сообщениями — в зависимости от используемых команд).

## 6. Конфигурация (`config.py`)

Ключевые настройки бота находятся в файле `config.py`. Важно правильно заполнить этот файл перед запуском бота.

*   `TOKEN`: Токен вашего Discord бота. **Никогда не публикуйте его!**
*   `GAME_CHANNEL_ID`: ID текстового канала, где будут проходить регистрации и отправляться основные сообщения игры.
*   `VOICE_CHANNEL_ID_TEAM1`: ID голосового канала для первой команды.
*   `VOICE_CHANNEL_ID_TEAM2`: ID голосового канала для второй команды.
*   `GUILD_ID`: ID вашего основного сервера Discord (используется для регистрации команд и некоторых проверок).
*   `VOTE_THRESHOLD`: Процент голосов (от 0.0 до 1.0), необходимый для принятия решения при голосовании за составы (например, `0.5` для 50%).
*   `VOTING_DURATION`: Продолжительность голосования в секундах.
*   `RESET_DELAY`: Время в секундах, через которое состояние игры будет автоматически сброшено при неактивности.
*   `MAX_PLAYERS_PER_TEAM`: Максимальное количество игроков в одной команде (по умолчанию 5).
*   `ADMIN_GUILD_IDS`: Список ID серверов, на которых будут доступны административные команды кога `AdminCog`. Если пуст, команды будут глобальными (но с проверкой прав Discord).
*   `BOT_ADMIN_USER_IDS`: Список ID пользователей Discord, которые считаются глобальными администраторами бота (для команд управления когами и других критически важных функций).

Убедитесь, что все ID указаны корректно.
